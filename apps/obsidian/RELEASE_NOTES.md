MarkPage for Obsidian candidate: an independent FileView using the same parsing,
formatting, pagination, annotations and source editor packages as the web app.

Open a Markdown note with the MarkPage command or file menu. The native default
view remains available. The plugin runs offline without a browser server.

Editing uses one guarded save queue per file. Native editing panes make MarkPage
read only; conflicts and deleted files retain local drafts for recovery or export.

This candidate requires real Windows Obsidian acceptance testing. The manifest's
1.8.7 minimum is a candidate SDK baseline, not a verified support claim. Review
the testing instructions in apps/obsidian/README.md before publishing this draft.
